## Features

- 🎨 The GNOME look everywhere in Steam, including the store and community pages
- 🌗 Light, dark or system color scheme
- 🖌️ GNOME accent colors
- ⚡ Lightweight and fast

## Installation

1. Install **[Millennium](https://steambrew.app)** and start Steam once.
2. Download the theme into Millennium's themes folder:

   ```sh
   # Linux
   cd ~/.local/share/Steam/millennium/themes
   git clone https://github.com/leoyd/steam-gnome-adwaita-millenium-theme.git
   ```

   ```powershell
   # Windows (PowerShell)
   cd "C:\Program Files (x86)\Steam\millennium\themes"
   git clone https://github.com/leoyd/steam-gnome-adwaita-millenium-theme.git
   ```

   No Git? Use **Code → Download ZIP** and extract it into that same folder.

3. In Steam, open **☰ → Millennium → Themes**, select **Adw Lite** and restart Steam.

To update, run `git pull` in the theme folder and restart Steam.

## Options

Colors, window buttons and a few library and store tweaks can be changed in
**Millennium → Themes → Adw Lite**.
